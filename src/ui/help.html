How to run bmv-trader

Every command runs in Terminal from the project folder.

cd ~/Documents/projects/bmv/bmv-trader
A trading day Start a session Watch it Stop new trades Clear STOP Close everything The engine stopped Research a strategy Keys When it refuses to start

A trading day

Times are New York time. On a half-day everything moves earlier; the engine reads the real times from Alpaca.

WhenYouThe engine
Before 09:25Check the account, start run, open the consoleStartup checks; refuses to start if anything is off
09:30–09:45NothingBuilds the 15-minute opening range
09:45–15:30Watch the lampTakes breakouts that pass the risk gate; Alpaca holds each stop and target
15:30NothingNo new entries after this
15:55NothingCloses everything, checks the account is flat, exits
AfterRead the journal; leave run stopped until tomorrowNot running

Start a paper session

  1. Check the account is reachable and flat: 
    cargo run --release -- status
  2. Start the engine and keep the Mac awake. Leave this window open all day: 
    caffeinate -i cargo run --release -- run
    Options, each logged as its own trial: --trend (only while SPY and the symbol trend up), --marketable (entry a little above the close so it fills), --symbols SPY,QQQ,....
  3. In a second window, open the console: 
    cargo run --release -- ui
    Open the link it prints. The link is the key to STOP and flatten, so don't share it. It changes every time you start ui.

Start once per day. A second run the same day is refused, because the engine can't yet rebuild today's trades and losses.

Watch it

The console and cargo run --release -- watch (terminal) show the same reading. Neither can change anything except through STOP and flatten.

LampMeansDo
TradingEngine running, nothing unresolvedNothing
PausedSomething can't be confirmed yet (for example market data); no new entries until it resolvesUsually clears by itself; check the banner
Engine not runningNo heartbeat from run for a minuteLook at the run window. Normal after 15:55
StoppedThe STOP file existsNothing, unless you want to clear it
HaltedA daily limit hit, or something unexplained; the engine closed everythingRead the halt reason. No more trading today
Engine down, positions openPositions exist but no engine manages themAlpaca still holds their stops and targets. Close everything if you want out now
UnknownThe journal can't be readCheck disk space and data/journal.jsonl
No session todayNo run today, or a weekend or holidayNothing
Stale readingThe last reading is over 20 s old; Alpaca or the console is slowWait; if it stays, check your connection

Stop new trades

In the console: type STOP under Emergency controls and press the button. Or in Terminal:

touch data/STOP

A running engine sees it within seconds, takes no new entries and cancels the entries still waiting to fill. Positions already open keep their stop and target at Alpaca and close normally.

Clear STOP

Only in Terminal, on purpose. The console has no button for it.

cat data/STOP    # who set it, and when
rm data/STOP

A running engine starts taking entries again on its next tick. If STOP is present when run starts, it refuses to start; clear STOP and start it again.

Close everything

In the console: type FLATTEN and press the button. Or in Terminal (works in paper and live):

cargo run --release -- flatten

It engages STOP first, then closes every position and cancels every order at Alpaca, and checks up to 10 times that the account is flat. It answers "flat" or tells you what's left. STOP stays engaged afterwards; clear it yourself if you want trading back. Last resort: close positions in Alpaca's own dashboard.

The engine stopped during the day

  1. Don't panic: every entry was sent as a bracket, so Alpaca holds its stop and target even with the Mac asleep.
  2. Read why it stopped: the last lines of the run window, and the console's journal.
  3. If you want out now, close everything.
  4. Don't start run again today; it refuses anyway. Start fresh tomorrow before 09:25.

If you installed the launchd backstop (deploy/README.md), it closes anything left from 3 minutes before the close on its own. It logs to data/backstop.log.

Research a strategy

A strategy trades with real money only after it passes the research gate on history. Results go to data/trials.jsonl and show in the console.

cargo run --release -- fetch --from 2020-08-03 --to 2025-12-31
cargo run --release -- backtest --from 2020-08-03 --to 2025-12-31 [--trend] [--marketable]
  • Every variant you test is a trial, and the more trials there are, the harder the gate. Try few, on purpose.
  • The last 3 months are the holdout, kept unseen. --holdout uses it once, at the end; a second look needs --holdout-again and makes the result less trustworthy.
  • fetch --allow-gaps accepts a day Alpaca has no data for (up to 5 per symbol), recorded as a day without trades.

Keys

Keys live in the macOS Keychain (service bmv-trader). Each command asks for the value, so it stays out of shell history:

security add-generic-password -s bmv-trader -a ALPACA_PAPER_KEY_ID -w
security add-generic-password -s bmv-trader -a ALPACA_PAPER_SECRET -w
  • Paper keys may sit in .env instead, but never in both places: that is refused.
  • Live keys are Keychain only, and run refuses live mode until P5.
  • To replace a key, add -U. To remove one: security delete-generic-password -s bmv-trader -a NAME
  • Never paste a key into chat, a commit or this console.
